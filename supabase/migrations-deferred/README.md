# هجراتٌ مؤجَّلةٌ بقرار

ملفٌّ فى `supabase/migrations` معناه **«طبِّقنى»**. فما كُتب ثمّ أُجِّل
بقرارٍ لا يُترك هناك، لأنّه قد يُطبَّق يوماً بلا قرارٍ جديد.

وما هنا **محفوظٌ لا ملغىً**: مكتوبٌ ومسمّى، ينتظر شرطَه. ونقلُه إلى
`supabase/migrations` هو الفعلُ الذى يعنى الموافقةَ على تنفيذه.

## v3.74.950 — سحبُ حقِّ الكتابة عن أعمدة المال

قِيس فى ٦ أغسطس ٢٠٢٦: الملفُّ **غيرُ مطبَّقٍ على القاعدة** و**غيرُ مسجَّلٍ
فى المشروع**. أى أنّه كان معلَّقاً بين اثنين: لا هو نُفِّذ، ولا هو حُفظ.
فنُقل إلى هنا ليُحفظ، ويبقى تنفيذُه قراراً يُتّخذ لا حادثةً تقع.
